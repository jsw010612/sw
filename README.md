# 다이버전스 레이더

코스피·코스닥 전 종목에서 **단계별 RSI 다이버전스**를 찾아 폰으로 알려 주는 프로그램이에요.
트레이딩뷰 지표와 같은 계산을 써요.

**구성**
- **스캐너 (GitHub에서 자동 실행):** 평일 장중 매시간(09:05~15:05, 장 마감 후 15:45) 분석해요.
- **폰 알림 (ntfy):**
  - 매수 신호가 85점 이상이면 바로 알림이 와요.
  - 매시간 "준비 순위 TOP20" 요약 알림이 와요 (재무 등급·⚠위험 표시 포함). 잠금화면에서 바로 보여요.
- **앱 (다이버전스 레이더):** 준비 순위·매수 신호 목록, 종목 상세 팝업(파동 차트, 프레임별 RSI, 조건 체크)을 볼 수 있어요.
- **홈 화면 위젯:** 준비 점수 상위 10종목이 재무 등급과 함께 매시간 갱신돼요. 종목을 누르면 앱에서 상세 화면이 열려요.

### 기준
- **1일봉이 기준이에요.** 다이버전스, 3파·5파, 거래량, 피보나치는 모두 1일봉에서 봐요.
- **1주 RSI가 40 이상이면** 1일봉 다이버전스를 바로 **매수 신호**로 봐요.
- **1주 RSI가 40 미만이면** 주봉이 아직 떨어지는 칼날일 수 있어서, 1일봉 다이버전스는 **⏳ 주봉 대기**로 표시해요. **주봉 다이버전스가 확정되면** 매수 신호가 떠요.
- 1시간·4시간 RSI는 진입 타이밍 참고용이에요 (과매도 부근에서 올라오는 중이면 가산점).

### 점수 세 가지
- **준비 점수 (100점):** 신호가 아직 완성되지 않아도 "곧 신호가 나올 만한 순서"예요.
  RSI 깊이 40 (1일·1주 위주) + 3파 거래량 급증 15 + RSI 다이버전스 형성 15 + 5파 진행도 15 + 거래량 감소 15
- **매수·대기 신호 점수 (100점):** 5파 저점이 확정된 신호예요.
  다이버전스 20 + 3파 거래량 10 + 거래량 다이버전스 10 + 5파 깊이 15 + 피보 구간 10 + 4파 되돌림 10 + 주봉 상태 15 + 단기 타이밍 10

- **재무 건강 점수 (100점, 참고용):** 결과 상위 150종목에 붙어요. 등급은 A·B·C·D·⚠위험이에요.
  수익성 25 + 안정성 25 + 성장성 20 + 지속성 15 + 가치 15
  ⚠위험 조건: 관리종목·거래정지 표시, 자본잠식 의심, 3년 연속 영업적자 (부채비율 400% 초과나 매출이 아주 작은 경우는 경고만 붙어요)
  데이터는 네이버 금융 "기업실적분석" 최근 연간 실적이고, 하루 한 번 새로 받아요.

### 내 종목 (관심·보유)
- 앱 🔍 검색으로 전 종목 중 아무거나 찾아 **관심** 또는 **보유(평단 입력)**로 추가할 수 있어요. 목록 밖 종목도 다음 실행부터 항상 분석돼요.
- 보유 종목 알림: **평단 -3%·-5% 손절선**, **+5% 단계마다 수익 알림**, **4파 고점(1차 익절) 도달**, **1일·1주 과매수 다이버전스(익절 신호)**
- 저장 위치는 저장소의 `state/watch.json`이에요. 공개 저장소라 종목과 평단은 남이 볼 수 있어요 (수량은 저장 안 함).
- 앱에서 저장하려면 설정에 **GitHub 토큰**이 필요해요 (아래 7단계).

---

## 1. 폰 알림 앱 준비 (ntfy)

1. 플레이스토어에서 **ntfy**를 설치해요.
2. 앱에서 **+ → 구독할 주제 이름**을 입력해요. 남이 못 맞히게 길게 지어 주세요.
   예: `sangwoo-div-7x93kq`
3. 잠금화면에 보이게 하려면, 폰 **설정 → 알림 → ntfy**에서 잠금화면 알림을 켜 두세요.

## 2. GitHub에 올리기

1. github.com에 가입하고 로그인해요.
2. 오른쪽 위 **+ → New repository**를 눌러요.
   - 이름: 예) `divergence-scanner`
   - **Public**(공개)으로 골라요. 앱과 위젯이 결과를 읽어 오려면 공개여야 해요. 저장소에는 코드와 종목 점수만 들어가고 개인정보는 없어요.
3. **Add file → Upload files**에서 압축을 푼 폴더 안 파일들을 **전부** 끌어다 놓아요.
   `.github` 폴더도 꼭 같이 올려야 해요. 숨김 폴더라 안 보이면 탐색기 **보기 → 숨긴 항목**을 체크하세요.
4. **Commit changes**를 눌러요.

## 3. 알림 주제 등록

1. 저장소 **Settings → Secrets and variables → Actions**로 가요.
2. **New repository secret**을 눌러요.
   - Name: `NTFY_TOPIC`
   - Secret: 1단계에서 지은 주제 이름

## 4. 스캐너 처음 실행

1. 저장소 **Actions** 탭을 열어요. 처음이면 enable 버튼을 눌러 켜요.
2. 왼쪽 **다이버전스 스캐너 → Run workflow**를 눌러요.
3. 첫 실행은 전 종목 일봉을 훑어서 **5~15분** 정도 걸려요.
4. 끝나면 `state/results.json`과 `state/latest.md`가 생겨요.

## 5. 앱 설치

1. 파일을 올리면 **앱 빌드**가 자동으로 돌아요. Actions 탭에서 초록 체크가 뜰 때까지 5분쯤 기다려요.
   안 돌았으면 왼쪽 **앱 빌드 → Run workflow**를 눌러요.
2. 폰으로 저장소 주소에 들어가서 오른쪽 **Releases → 다이버전스 레이더 앱 (최신)**에서 **DivRadar.apk**를 내려받아요.
3. 설치할 때 "출처를 알 수 없는 앱"을 물어보면 허용해요.
4. 앱을 열고 오른쪽 위 **⚙ 설정**에 `아이디/저장소이름`(예: `sangwoo/divergence-scanner`)을 넣고 저장해요.

## 6. 위젯 추가

홈 화면 빈 곳을 길게 누르고 **위젯 → 다이버전스 레이더 → 레이더 TOP5**(위젯 이름)를 끌어다 놓아요.
- 1시간마다 자동으로 갱신돼요. ⟳ 버튼을 누르면 바로 갱신돼요.
- 종목을 누르면 앱의 상세 화면이 열려요.
- 잠금화면 위젯은 폰 기종마다 지원이 달라요. 갤럭시는 **설정 → 잠금화면 → 위젯**에서 목록에 뜨면 추가할 수 있어요. 안 뜨면 ntfy 요약 알림으로 잠금화면에서 확인하세요.

## 7. GitHub 토큰 만들기 (관심·보유 저장용)

1. GitHub 오른쪽 위 프로필 사진 → **Settings** → 왼쪽 맨 아래 **Developer settings**
2. **Personal access tokens → Fine-grained tokens → Generate new token**
3. Token name은 아무거나 (예: `radar`), Expiration은 1년 정도로 골라요.
4. **Repository access → Only select repositories**에서 이 저장소(`sw`)만 골라요.
5. **Permissions → Repository permissions → Contents**를 **Read and write**로 바꿔요.
6. **Generate token**을 누르고 나온 `github_pat_...` 값을 복사해요. 이 화면을 벗어나면 다시 볼 수 없어요.
7. 앱 ⚙ 설정의 **GitHub 토큰** 칸에 붙여 넣고 저장해요. 토큰은 그 기기에만 저장돼요.

## 설정 바꾸기

**Settings → Secrets and variables → Actions → Variables** 탭에서 아래 이름으로 값을 넣으면 돼요.

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `MIN_SCORE` | 85 | 이 점수 이상 매수 신호만 폰 알림 |
| `WATCH_SCORE` | 70 | 이 점수 이상은 latest.md에 기록 |
| `PROFIT_STEP` | 5 | 보유 종목 수익 알림 간격 (%) |
| `UNIVERSE` | ALL | `ALL` = 전 종목, `300` 같은 숫자 = 시총 상위 N개만 |
| `SUMMARY` | 1 | `0`으로 하면 매시간 요약 알림 끄기 |

RSI 기준(30/35), 저점 판단 봉 수, 피보나치 비율 같은 세부 숫자는 `analysis.py` 맨 위 `Params`에서 바꿀 수 있어요.

## 알아 둘 점

- 1시간봉은 야후 무료 시세라 **몇 분 정도 늦을 수 있어요.** 일봉·주봉·월봉은 네이버 시세를 써요. NXT(넥스트장) 시간대는 포함되지 않아요.
- GitHub 예약 실행은 몇 분씩 늦게 시작될 때가 있어요.
- 야후가 GitHub 서버 요청을 막으면 실행 기록에 "1시간봉 0개 받음"이 떠요. 계속 그러면 한국투자증권 API로 바꾸면 돼요.
- 앱은 매번 같은 서명으로 빌드되게 해 둬서, 새 버전 APK를 그냥 덮어 설치하면 돼요.
- 신호는 참고용이에요. 매수 판단과 책임은 본인에게 있어요.

## PC에서 직접 돌리기 (선택)

```
pip install -r requirements.txt
set NTFY_TOPIC=내주제이름
python scan.py --test-push   (알림이 오는지 확인)
python scan.py               (스캔 한 번 실행)
```
